# PawPath 댕댕 산책각

**Every Paw Deserves a Perfect Path.**

AI-Powered Personalized Pet Walking Recommendation

PawPath는 반려동물의 나이, 크기, 활동량, 성격, 산책 선호도와 보호자의 일정을 분석하고, 실시간 날씨와 동네 환경의 위험을 평가해 오늘 가장 좋은 산책 시간과 코스를 추천하는 서비스입니다. 산책 후 남긴 피드백을 학습해 반려동물이 실제로 좋아하는 코스와 시간대를 다음 추천에 반영합니다.

> 낯선 길을 싫어하는 두부를 위해 익숙한 공원 코스를 골랐어요. 비가 오기 전 짧게 다녀올 수 있어요.

위 문장은 고정 문구가 아니라 두부의 프로필, 코스 데이터, 시간별 예보로 계산해 만든 결과입니다.

## 핵심 기능

- **펫밸런스:** 프로필에서 권장 산책량과 성향 값을 계산해 산책 시간과 강도를 맞춥니다.
- **비켜비:** 시간별 강수, 기온, 바람, 자외선을 반려동물 기준으로 평가해 궂은 시간을 피합니다.
- **안심귀가:** 해가 진 뒤에는 조명 비중을 높이고, 공원과 기록된 시설을 함께 평가합니다.
- **산책 안전 지수:** 날씨, 조명, 차량 노출, 노면, 그늘을 항목별로 평가해 위험 코스를 제외하고 대체 코스를 제안합니다. 데이터가 없는 항목은 "확인 불가"로 표시하고 안전하다고 보지 않습니다.
- **피드백 학습:** 코스 선호도와 시간대 선호를 학습하고, 비슷한 코스로 일반화합니다. 피드백이 쌓일수록 과거 만족도를 더 강하게 반영합니다.
- **근거 있는 설명:** 추천 이유와 주의사항을 실제 데이터로만 만듭니다. 추정값은 추정이라고 표시합니다.
- **AI 추천 문장 (선택):** 로컬 LLM이 계산 결과를 친근한 문장으로 다듬습니다. 사실 검증을 통과한 문장만 쓰고, 점수는 바꾸지 못합니다.
- **GPS 길 안내:** 현재 위치에서 코스 출발점까지 도보로 안내하고, 코스에서는 회전 방향과 진행률을 알려 줍니다. 코스를 벗어나면 돌아갈 길을 다시 찾습니다.
- **산책 중 재평가:** 날씨가 나빠지면 복귀 경로와 지금 걷기 좋은 대체 코스를 안내합니다.
- **나만의 산책길:** 직접 걸은 길을 GPS로 기록해 사진과 함께 저장하고, GPX 파일로 가져오거나 내보내며, 공유 링크로 나눕니다.
- **보호자 계정 (선택):** 아이디나 Google 계정으로 로그인하면 반려동물, 추천, 산책 기록, 산책길이 계정별로 나뉩니다. 로그인하지 않으면 지금처럼 시연 보호자로 씁니다.
- **주간 리포트:** 거리, 시간, 만족도 변화, 지난주 대비, 추천과 실제 선택을 비교합니다. 시연용 산책은 통계에서 뺍니다.

## 빠른 시작

필요 도구: Python 3.12 이상, [uv](https://docs.astral.sh/uv/), Node.js 20 이상. API 키는 필요 없습니다.

```bash
./dev.sh
```

의존성을 설치한 뒤 백엔드와 프론트엔드를 함께 띄우며, `Ctrl+C`로 함께 종료합니다. macOS와 Linux용 스크립트이므로 Windows에서는 아래 **따로 실행하기**를 따르세요.

- 앱: http://localhost:5173
- API 문서(Swagger): http://localhost:8000/docs

처음 실행하면 DB(`backend/pawpath.db`)를 만들고, 산책 코스(망원동 10개, 개포동 6개)와 시연용 반려동물 두부, 기본 일정(16~20시)을 넣습니다. 기본 지역은 망원동입니다. 이전 버전의 DB가 있으면 데이터를 유지한 채 새 컬럼을 자동으로 추가합니다.

### 따로 실행하기

```bash
# 백엔드
cd backend
uv sync
uv run uvicorn app.main:app --port 8000

# 프론트엔드 (다른 터미널)
cd frontend
npm install
npm run dev
```

uv가 없다면 Python 3.12 가상환경을 켜고 `backend` 폴더에서 다음을 실행하세요.

```bash
pip install fastapi "uvicorn[standard]" sqlalchemy pydantic pydantic-settings httpx
uvicorn app.main:app --port 8000
```

cp .env.example .env

## AI 추천 문장 켜기 (선택)

기본값은 꺼짐이며, 꺼져 있어도 나머지 기능은 모두 동작합니다. 켜려면 [Ollama](https://ollama.com)를 실행하고 모델을 받습니다. API 키는 필요 없습니다.

```bash
ollama pull gemma4:e4b
```

그다음 `.env`에 아래 값을 넣고 서버를 다시 시작합니다. 다른 모델을 쓰려면 `LLM_MODEL`을 바꾸세요.

```
LLM_PROVIDER=ollama
```

추천 화면은 계산 결과로 만든 문장을 먼저 보여 주고, 사실 검증을 통과한 AI 문장이 오면 바꿉니다. LLM이 응답하지 않거나 근거 없는 내용을 쓰면 처음 문장을 그대로 씁니다.

## 로그인 (선택)

기본값은 로그인 없이 시연 보호자로 쓰는 방식이라 시연 흐름은 그대로입니다. 머리글의 **로그인**에서 가입하면 그 계정의 반려동물, 일정, 추천, 산책 기록, 나만의 산책길, 사진이 다른 계정과 시연 보호자에게서 완전히 나뉩니다. 다른 계정의 데이터는 주소를 알아도 `404`입니다.

로그인을 필수로 하려면 `.env`에 `AUTH_REQUIRED=true`를 넣고 서버를 다시 시작하세요. 로그인하지 않은 사용자는 로그인 화면으로 이동하고, 공유 링크와 공개 산책길, 코스와 날씨만 로그인 없이 열립니다.

| 항목 | 방식 |
|---|---|
| 비밀번호 | 표준 라이브러리 scrypt로 해시. 원문은 저장하지 않음 |
| 세션 | 30일. HttpOnly, SameSite=Lax 쿠키이고 HTTPS 접속이면 Secure를 붙임. DB에는 토큰의 SHA-256 값만 저장 |
| 로그인 시도 제한 | 같은 아이디로 5번 연달아 틀리면 10분 동안 막음 |
| 세션 만료 | 만료된 쿠키로는 시연 보호자의 데이터도 보여 주지 않고, 화면에 다시 로그인하라고 안내 |

비밀번호 찾기와 이메일 인증은 없습니다. 로그인 시도 제한은 서버 메모리에 두므로 서버를 다시 시작하면 초기화됩니다.

### Google 로그인 켜기 (선택)

Google 클라이언트 값을 넣으면 로그인 화면에 **Google로 계속하기** 버튼이 생깁니다. 값이 없으면 버튼이 보이지 않고 나머지는 그대로 동작합니다.

1. [Google Cloud 콘솔](https://console.cloud.google.com/)에서 프로젝트를 만듭니다.
2. **Google 인증 플랫폼**(OAuth 동의 화면)에서 앱 이름과 지원 이메일을 넣고, 대상을 **외부**로 정합니다. 게시하기 전에는 **테스트 사용자**에 넣은 Google 계정만 로그인할 수 있으니 시연할 계정을 추가하세요.
3. **클라이언트 > 클라이언트 만들기**에서 유형을 **웹 애플리케이션**으로 고르고, **승인된 리디렉션 URI**에 `http://localhost:5173/api/auth/google/callback`을 넣습니다.
4. 발급된 클라이언트 ID와 보안 비밀을 `.env`에 넣고 서버를 다시 시작합니다.

```
GOOGLE_CLIENT_ID=123456789-xxxx.apps.googleusercontent.com
GOOGLE_CLIENT_SECRET=GOCSPX-xxxx
```

5. 앱을 **`http://localhost:5173`**으로 엽니다. `127.0.0.1:5173`으로 열면 돌아오는 주소와 호스트가 달라 "시작한 주소와 돌아온 주소가 달라요" 오류가 납니다.

휴대폰에서 터널로 쓰려면 고정 주소가 필요합니다. `cloudflared tunnel --url`의 임시 주소는 실행할 때마다 바뀌어 매번 콘솔에 등록해야 하므로, 고정 도메인(이름 있는 Cloudflare 터널이나 ngrok 고정 도메인)의 `https://도메인/api/auth/google/callback`을 콘솔에 등록하고 같은 값을 `GOOGLE_REDIRECT_URI`에 넣으세요.

| 항목 | 방식 |
|---|---|
| 흐름 | OpenID Connect 승인 코드 흐름. 코드 교환은 서버가 클라이언트 비밀값으로 하고, 브라우저에는 토큰이 오가지 않음 |
| 위조 방지 | PKCE(S256), nonce, state. state는 시작한 브라우저의 쿠키와 맞아야 하고 10분 안에 한 번만 쓸 수 있음 |
| 토큰 확인 | 서버가 Google에서 직접 받은 ID 토큰의 발급자, 대상(클라이언트 ID), 만료, nonce 확인 |
| 사용자 구분 | Google 고유 ID(`sub`). 이메일은 Google이 확인한 경우에만 표시용으로 저장 |
| 요청 범위 | `openid email profile`만 요청. Google 데이터에 접근하는 토큰은 저장하지 않음 |
| 로그 | 돌아오는 주소의 승인 코드와 state를 접근 로그에서 지움 |

## 시연 순서

1. **홈:** 두부 정보, 현재 날씨, 산책 가능 시간을 확인하고 **추천 시작**을 누릅니다.
2. **추천:** 날씨 조건에서 **곧 비**를 고릅니다. 위의 추천 문장과 TOP 3, 안전 평가, 점수 근거를 볼 수 있습니다. 피드백을 남기기 전이라면 어느 시각에 시연해도 같은 문장이 나옵니다. AI 문장을 켜면 이 문장 대신 AI 문장이 표시됩니다.
3. **지도:** 코스를 고르면 경로, 코스 주변 시설, 데이터 출처를 볼 수 있습니다.
4. **산책:** 2위 코스에서 **이 코스로 산책**을 누르면 길 안내 지도가 열립니다. 망원동이 아닌 곳에서 시연한다면 **시연용 위치로 걷기**를 누르세요. 코스를 따라 움직이며 안내가 바뀝니다. **산책 끝내기**를 누르고 만족도 5점 피드백을 남깁니다.
5. **달라진 추천 보기:** 피드백한 코스가 1위로 오르고 "학습 효과"와 순위 변화가 표시됩니다.
6. **마이페이지와 주간 리포트:** 코스 선호도, 학습된 취향, 추천 결과 변화를 확인합니다. 주간 리포트에서는 시연용 산책이 통계에서 빠진 것도 볼 수 있습니다.

**실제 날씨** 외의 조건(곧 비, 폭염, 한파, 폭우)은 시연용 시나리오이며 화면에 그렇게 표시됩니다. 폭염에서는 더운 시간과 그늘을 확인할 수 없는 긴 코스가 제외되고, 폭우에서는 실내 대안을 안내합니다.

산책 중 날씨 변화를 보려면 시연용 위치로 걷는 도중 **시연: 지금부터 비 내리기**를 누르세요. 복귀 경로와 대체 코스가 안내되고, **출발점으로 돌아가기**를 고르면 복귀 안내가 시작됩니다.

시연 내용을 지우려면 서버를 끄고 `backend/pawpath.db`를 삭제한 뒤 다시 실행하세요.

## 개포동 코스로 전환

기본 지역은 망원동입니다. 발표 장소인 개포디지털혁신파크 새롬관 근처에서 실제 GPS로 걸어 보려면 개포동 코스로 전환하세요. 서버를 끄고 아래처럼 다시 실행합니다.

```bash
SERVICE_AREA=gaepo ./dev.sh
```

계속 쓰려면 `.env`에 `SERVICE_AREA=gaepo`를 넣으세요. 추천, 지도, 대체 코스가 이 지역의 코스만 쓰고 날씨 좌표도 함께 바뀝니다. 코스와 산책 기록은 DB에 모두 남으므로 지역을 바꿔도 지워지지 않습니다.

| 코스 | 거리 | 예상 시간 | 특징 |
|---|---|---|---|
| 개포동 근린공원 양재천변 코스 | 1.35km | 20분 | 공원과 강변길, 일상 코스 |
| 개포로88길 골목 코스 | 0.96km | 15분 | 동네 골목, 일상 코스. 큰길로 표시된 구간이 24% |
| 양재천 영동6교 왕복 | 1.65km | 30분 | 강변길 왕복, 일상 코스 |
| 양재천 서쪽 강변 왕복 | 2.36km | 40분 | 강변길 왕복 |
| 달터근린공원 숲길 | 2.34km | 40분 | 흙길이 있는 숲길. 출발점이 발표장에서 약 1.5km |
| 양재천 탄천 종주 코스 | 4.24km | 70분 | 탄천 자전거길까지 왕복하는 긴 코스 |

경로와 시설은 OpenStreetMap 기준이며, 혼잡도와 그늘 같은 추정값은 현장에서 확인한 값이 아닙니다.

## GPS 길 안내

**이 코스로 산책**을 누르면 전체 화면 지도가 열리고 현재 위치를 따라 안내합니다.

| 상황 | 안내 |
|---|---|
| 출발점에서 3km 초과 | 코스 위치를 보여 주고, 카카오맵 길찾기와 시연용 걷기를 제공 |
| 출발점에서 3km 이내 | 실제 도보 경로로 출발점까지 안내 (길찾기 서버 실패 시 직선 표시) |
| 코스 위 | 다음 회전 방향과 거리, 진행률, 남은 거리와 시간. 내 위치를 따라 지도 이동 |
| 코스 이탈 (약 35m 초과) | 벗어난 거리를 알리고 돌아갈 도보 경로를 다시 찾아 점선으로 표시. 돌아오면 이어서 안내 |
| 날씨 악화 | 5분마다 또는 **대체 경로** 버튼으로 재평가. 복귀 경로와 대체 코스 안내 |
| 완주 또는 산책 끝내기 | 실제 걸은 시간과 거리로 기록하고 피드백 화면으로 이동 |
| GPS 사용 불가 | 이유를 안내하고 시연용 걷기나 GPS 없이 기록하기를 제공 |

시연용 걷기는 코스 예상 시간으로 기록하고 활동 통계에서 뺍니다. 피드백 학습에는 반영됩니다.

**브라우저는 HTTPS나 localhost에서만 위치 정보를 허용합니다.** 같은 컴퓨터의 `http://localhost:5173`에서는 바로 동작하지만, 휴대폰에서 `http://192.168.x.x:5173`으로 접속하면 막힙니다. 휴대폰에서 실제 GPS를 쓰려면 HTTPS 터널을 여세요. Vite 설정에 아래 두 도구의 주소를 허용해 두었습니다.

```bash
./dev.sh
cloudflared tunnel --url http://localhost:5173   # 또는: ngrok http 5173
# 출력된 https 주소를 휴대폰에서 엽니다
```

**위치 정보 처리:** 길 안내 중의 위치는 저장하지 않으며 서버 로그에도 남기지 않습니다. 코스 위에서는 브라우저 안에서 계산합니다. 출발점 길찾기, 복귀 경로, 이탈 시 재탐색을 할 때만 좌표를 OSRM 도보 경로 서버로 보냅니다. 경로가 저장되는 것은 아래 [나만의 산책길](#나만의-산책길과-gpx)에서 사용자가 기록을 저장할 때뿐이고, 저장한 산책길을 추천 후보로 등록하면 경로가 지나는 범위를 OpenStreetMap Overpass 서버에 보내 주변 환경을 측정합니다.

**날씨 재평가의 한계:** 시간별 예보로 판단합니다. 실시간 강수 감지가 아니므로 하늘 상태도 함께 살펴 주세요.

## 나만의 산책길과 GPX

추천 코스와 별개로, 직접 걸은 길을 기록해 모아 둘 수 있습니다. **산책 기록** 메뉴의 **GPS로 산책 기록**이나 **마이 > 나의 산책길**에서 시작합니다.

| 기능 | 동작 |
|---|---|
| 산책 기록 | 시작, 일시정지, 재개, 종료. 지도에 이동 경로와 현재 위치를 그리고 거리, 시간, 평균 속도를 보여 줌 |
| GPS 오차 거르기 | 정확도 50m를 넘는 좌표, 제자리 흔들림, 시속 43km를 넘는 순간 이동은 거리에 넣지 않음. 튄 위치가 같은 곳에 3번 연달아 찍히면 실제로 옮겨 간 것으로 보고 새 구간으로 이음 |
| 기록 유실 방지 | 좌표를 받을 때마다 기기(localStorage)에 임시 저장. 새로고침하거나 앱이 닫혀도 다시 열면 일시정지 상태로 불러옴. 저장이 실패해도 기록을 지우지 않고, 다시 저장해도 한 번만 저장됨 |
| 저장 | 이름, 반려동물, 메모, 공개 범위. 거리와 평균 속도는 서버가 좌표로 다시 계산하고, 일시정지 구간 사이는 거리에 넣지 않음 |
| 나의 산책길 | 경로 썸네일 목록. 최근 기록순, 거리순 정렬과 반려동물별, 공개 범위별 보기. 상세 화면에서 수정, 삭제, GPX 다운로드, 공유 |
| 사진 | 저장할 때나 상세 화면에서 5장까지. 브라우저에서 1600px JPEG로 다시 그려 올리고, 서버도 EXIF(촬영 위치), XMP, 주석, 끝에 붙은 보조 이미지를 지운 뒤 저장. 사진은 주인만 보고 공유 화면에는 나오지 않음 |
| GPX 가져오기 | 파일 선택이나 끌어다 놓기. 업로드 진행률, 검증 결과, 경로 미리보기를 보여 준 뒤 저장. GPX 1.0과 1.1의 트랙(`trk`)과 경로(`rte`)를 읽고, 여러 트랙과 구간, 시각 없는 파일, 같은 경로의 중복 가져오기를 알려 줌 |
| GPX 내보내기 | GPX 1.1, UTF-8. 구간, 시각(UTC), 고도를 그대로 담음. 파일 이름은 `pawpath_산책길-이름_20261031.gpx` |
| 공유 | 링크 공유는 추측할 수 없는 32자 토큰을 쓰고 기간(7일, 30일)을 정할 수 있음. 링크 해제, 비공개 전환 시 예전 링크는 다시 열리지 않음. 공개로 두면 공개 산책길 목록에 올라감 |
| 산책길 만들기 | 출발 위치(현재 위치 또는 지도에서 선택)와 산책 시간으로 도보 길찾기를 이용해 순환 경로 후보를 최대 5개 만들어 비교하고 내 산책길로 저장. 기준(시간 오차, 되돌아오는 구간)을 못 넘으면 만들지 못했다고 알림. 반려동물을 고르면 후보를 그 아이의 성향·날씨·일정과 주변 환경(도로, 조명, 나무, 공원, 시설)으로 평가해 맞는 순서로 보여 줌(경사·반려견 출입은 평가하지 않음) |
| 추천 후보 | 상세 화면의 **추천 후보에 넣기**로 내 산책길을 추천 후보 코스로 등록. 공용 코스와 같은 엔진으로 점수를 매기고, 지도와 길 안내, 피드백 학습도 같게 동작. 나에게만 보임 |

**공유 화면에서 빠지는 정보:** 걸은 시각, GPS 정확도, 반려동물, 보호자 정보는 보내지 않습니다. 메모는 허용했을 때만 보이고, 공유용 GPX에는 시각과 고도를 넣지 않습니다. 경로 자체에는 집 주소 같은 위치가 드러날 수 있어 공유 화면을 만들 때 안내합니다.

**추천 후보로 쓸 때:** 주변 도로, 조명, 노면, 나무, 공원은 시드 코스와 같은 방법으로 OpenStreetMap에서 측정합니다. 공개 Overpass 서버가 느려(실측 15~40초) 등록은 바로 끝내고 측정은 뒤에서 하며, 그동안이나 측정에 실패한 항목, 측정할 수 없는 혼잡도와 경사는 "확인 불가"로 계산하고 안전하다고 보지 않습니다. 직접 기록한 길은 반려견이 걸어 본 익숙한 길로, 가져온 GPX는 낯선 길로 봅니다. 서비스 지역(망원동, 개포동) 5km 안에서 출발하는 0.1~10km 산책길만 등록할 수 있고, 끊긴 구간 사이가 100m를 넘으면 하나의 코스로 잇지 않습니다. 등록할 때 경로가 지나는 범위(사각형 좌표)를 Overpass 서버에 보냅니다.

**제한:** GPX 파일은 10MB, 10만 지점까지 가져옵니다. 사진은 JPG와 PNG만 장당 5MB까지 저장합니다(화면에서 고르면 다른 형식도 JPEG로 바꿔 올림). 보안을 위해 DOCTYPE이나 엔티티 선언이 있는 파일은 읽지 않습니다(XXE 방지). 휴대폰 화면이 꺼지거나 다른 앱으로 넘어가면 브라우저가 위치 수집을 멈추므로, 화면을 켠 채로 걸어야 합니다. 그 사이 구간은 선을 잇지 않고 거리에서 뺍니다.

## 데이터와 안전에 관한 안내

- 코스 경로, 주변 시설, 도로 유형은 OpenStreetMap 기준입니다. 조명과 노면도 OSM 기록이 충분한 코스만 기록값을 쓰고, 나머지는 "확인 불가"로 표시합니다.
- 혼잡도, 그늘, 난이도, 코스별 동반 가능 여부는 팀 추정값이며 현장 확인이 필요합니다. 코스는 시연용으로 만든 것이며 팀이 현장에서 걸어 보며 확인한 것은 아닙니다.
- "반려동물 동반 표시 장소"는 OSM 표시 기준이며 실제 출입 가능 여부를 보장하지 않습니다.
- 안전 점수와 날씨 적합도는 환경 위험을 비교하는 참고값으로, 의학적, 절대적 안전을 보장하지 않습니다. 반려동물의 건강 상태와 현장 상황을 먼저 살펴 주세요.
