# PawPath (댕댕 산책각) 개발 계획

Every Paw Deserves a Perfect Path.

## 환경 분석 결과

| 항목 | 확인 내용 | 결정 |
|---|---|---|
| 프로젝트 폴더 | 비어 있음 | 신규 구축, `backend/` · `frontend/` · `docs/` 분리 |
| Python / uv | 3.12, uv 0.9 | `uv`로 가상환경과 잠금 파일 관리 |
| Node | 20.20 | Vite + React + TypeScript + Tailwind CSS |
| PostgreSQL | 미설치 | SQLite 기본, `DATABASE_URL`로 교체 가능 |
| Open-Meteo | 키 없이 호출 가능 | 실제 날씨 기본 제공자, 실패 시 Mock으로 전환 |
| 지도 | Kakao 키 없음, OSM 타일 응답 정상 | Leaflet + OpenStreetMap |
| 코스 데이터 | Overpass, OSRM 도보 경로 응답 정상 | 망원동 일대 실제 경로와 시설을 시드로 저장 |

## 심사 기준 반영

- **기술 완성도:** 단순 호출이 아닌 직접 개발에 가산점이 있으므로 추천 엔진을 외부 AI 호출 없이 직접 구현한다.
- **라이브 시연 안정성:** 외부 API가 모두 실패해도 시드 데이터와 Mock 날씨로 끝까지 동작한다.
- **외부 자원 내역:** 미기재 시 실격이므로 `docs/EXTERNAL_RESOURCES.md`를 가이드 표 형식으로 관리한다.

## 단계

1. 코스 데이터 빌더: 경유지 정의 → 도보 경로 계산 → 경로 주변 시설 수집 → `courses.json` 생성
2. 백엔드 기반: 설정, DB 모델, 시드, 날씨 제공자
3. 추천 엔진: 특성값, 시간대 점수, 코스 점수, 학습, 설명 (DB와 무관한 순수 모듈)
4. API: 반려동물, 일정, 날씨, 코스, 추천, 산책, 피드백, 분석
5. 프론트엔드: 대시보드, 프로필, 추천, 지도, 산책 기록, 마이페이지
6. 검증: 단위 테스트, API E2E, 브라우저 E2E
7. 문서: README, 아키텍처, API 명세, 외부 자원 내역
