# 기능 안내

mungo를 처음 쓰는 보호자가 반려동물을 등록하고, 추천을 받아 산책하고, 피드백을 남기기까지의 흐름입니다. 화면 이름과 버튼은 실제 앱(커밋 `5f74f2d`) 기준입니다. 구현 방식은 [시스템 아키텍처](ARCHITECTURE.md), 요청과 응답은 [API 명세](API.md), 기능별 구현과 검증 상태는 [기능 정리](FEATURES.md)에 있습니다.

## 1. 시작하기

- **바로 써 보기:** 공개 데모 https://pawpath.ficklebobo.dev 를 휴대폰 브라우저로 엽니다.
- **내 컴퓨터에서:** `./dev.sh`로 실행하고 http://localhost:5173 을 엽니다([빠른 시작](../README.md#빠른-시작)).
- **로그인 없이:** 처음에는 시연 보호자와 시연용 반려동물 두부, 기본 일정(16~20시)으로 시작합니다. 같은 서버를 쓰는 누구나 시연 보호자 데이터를 함께 보므로, 내 기록만 남기려면 Google로 로그인하세요.

모바일 웹을 먼저 생각하고 만들었습니다. 폰에서는 아래 메뉴, 넓은 화면에서는 머리글 메뉴로 이동합니다.

| 메뉴 | 화면 | 하는 일 |
|---|---|---|
| 홈 | `/` | 반려동물 이름표, "내일 두부 산책은 오전 7시가 좋아요" 같은 한 줄 답, 시간대별 산책 점수 막대와 날씨 지표, 오늘의 추천 코스, 다른 코스 |
| 커뮤니티 | `/community` | 다른 보호자가 공유한 산책길 탐색, 저장, 후기 |
| 산책 (가운데 버튼) | 시트 | 추천 코스로 산책(`/recommend`), 내 길로 GPS 기록(`/record`), 다녀온 산책 기록(`/walk`), 산책길 자동 만들기(`/generate`) |
| 지도 | `/map` | 조건(오늘 추천, 30분 이하, 공원, 그늘 많음)으로 코스를 거르고 거리·시간·그늘을 표로 비교. 줄을 누르면 지도와 상세가 펼쳐지고, 왼쪽으로 밀면 바로 길 안내 시작 |
| 마이 | `/my` | 산책 리포트, 코스 선호도, 학습된 취향, 시간대 선호, 피드백 기록, 계정·가족 프로필 |

브랜드 색과 디자인 원칙은 [PRODUCT.md](../PRODUCT.md)에 있습니다.

## 2. 로그인 및 계정

기본값은 로그인 없이 시연 보호자로 쓰는 방식이라 시연 흐름은 그대로입니다. 머리글의 **로그인**에서 Google로 로그인하면(처음이면 바로 가입) 그 계정의 반려동물, 일정, 추천, 산책 기록, 나만의 산책길, 사진이 다른 계정과 시연 보호자에게서 완전히 나뉩니다. 다른 계정의 데이터는 주소를 알아도 `404`입니다. Google 클라이언트 설정은 [Google 로그인 켜기](SETUP.md#google-로그인-켜기)에 있습니다.

로그인을 필수로 하려면 `.env`에 `AUTH_REQUIRED=true`를 넣고 서버를 다시 시작하세요. 로그인하지 않은 사용자는 로그인 화면으로 이동하고, 공유 링크와 공개 산책길, 코스와 날씨만 로그인 없이 열립니다.

| 항목 | 방식 |
|---|---|
| 로그인 방식 | Google만(OAuth 2.0, PKCE). 아이디와 비밀번호 로그인은 2026-11-01에 없앰 |
| 세션 | 로그인한 지 30일이 지나거나 7일 동안 쓰지 않으면 끝남. HttpOnly, SameSite=Lax 쿠키이고 HTTPS 접속이면 Secure를 붙임. DB에는 토큰의 SHA-256 값만 저장 |
| 세션 만료 | 시연 보호자로 넘어가지 않고 보던 화면 위에서 Google 다시 로그인을 안내함. 로그인하면 보던 주소로 돌아오고, 저장하지 않은 산책 기록은 기기에 남아 이어서 저장함. 화면에 입력하던 내용은 Google로 다녀오는 동안 사라짐. 다른 계정으로 로그인하면 앞사람의 기록을 지움 |
| 본인 재확인 | 탈퇴 전에 Google로 다시 확인. 로그인이나 확인 뒤 10분 동안 유효하고, 확인하면 세션 토큰을 바꿈 |

### Google 로그인 방식

| 항목 | 방식 |
|---|---|
| 흐름 | OpenID Connect 승인 코드 흐름. 코드 교환은 서버가 클라이언트 비밀값으로 하고, 브라우저에는 토큰이 오가지 않음 |
| 위조 방지 | PKCE(S256), nonce, state. state는 시작한 브라우저의 쿠키와 맞아야 하고 10분 안에 한 번만 쓸 수 있음 |
| 토큰 확인 | 서버가 Google에서 직접 받은 ID 토큰의 발급자, 대상(클라이언트 ID), 만료, nonce 확인 |
| 사용자 구분 | Google 고유 ID(`sub`). 이메일은 Google이 확인한 경우에만 표시용으로 저장 |
| 요청 범위 | `openid email profile`만 요청. Google 데이터에 접근하는 토큰은 저장하지 않음 |
| 로그 | 돌아오는 주소의 승인 코드와 state를 접근 로그에서 지움 |

## 3. 반려동물 등록

반려동물이 없으면 홈과 마이에 **반려동물 등록하기**가 보입니다. 등록한 반려동물은 홈의 이름표(말티즈 | 5세 | 4.2kg …)를 눌러 고치고, 여러 마리는 **가족 반려동물 > 관리**에서 봅니다. 입력한 값으로 산책 시간과 코스가 달라집니다.

| 묶음 | 항목 | 추천에 쓰이는 곳 |
|---|---|---|
| 기본 | 이름, 견종, 나이(세), 체중(kg) | 생애 단계(어린 강아지, 성견, 노령견), 쾌적 체감온도 |
| 산책 성향 | 크기, 평소 활동량, 성격, 산책 선호도(익숙한 길·새 길), 더위 민감도, 낯선 환경에 대한 반응 | 권장 산책 시간과 거리, 낯선 길·혼잡·오르막 허용도 |
| 선호하는 산책 (선택) | 선호 거리, 선호 시간대 | 사용자 선호 점수 |

**보호자 일정**은 홈 시간표의 **변경**(예: 16시 ~ 20시 변경)에서 산책 가능 시간(시작·끝나는 시각, 직접 입력한 시간 추가)과 하루 희망 횟수를 정합니다. 추천 시간은 이 안에서만 고릅니다. 가족 프로필을 쓰면 일정은 프로필마다 따로 둡니다.

어떤 값이 어떻게 쓰이는지는 [추천 알고리즘의 반려동물 프로필](RECOMMENDER.md#반려동물-프로필)에 있습니다.

## 4. 산책 추천 이용

<img src="images/screens/home.webp" width="240" alt="홈 화면. 오늘 두부 산책은 오후 7시가 좋아요, 시간대별 산책 점수" align="right" />

**홈**은 "오늘 두부 산책은 오후 7시가 좋아요"처럼 한 줄로 답하고, 보호자 일정 안의 시간대별 점수 막대를 보여 줍니다. 막대를 누르면 그 시간의 강수·습도·바람·자외선이 바뀝니다. 아래에는 오늘의 추천 코스가 있습니다.

**다른 코스와 추천 근거 보기**를 누르면 추천 화면(`/recommend`)으로 갑니다. 맨 위 **날씨 조건**에서 실제 날씨(시간별 예보) 대신 시연용 조건(곧 비, 폭염, 한파, 폭우)을 고를 수 있고, 시연용 조건은 화면에 그렇게 표시됩니다.

날씨는 Open-Meteo의 시간별 예보입니다. 지금 내리는 비를 감지하지 않으니 하늘 상태도 함께 살펴 주세요.

## 5. 추천 결과 확인

<img src="images/screens/safety.webp" width="240" alt="안전 평가 펼침. 안전 76점 주의와 항목별 상태, 출처" align="right" />

추천 화면은 코스 TOP 3를 카드로 보여 줍니다. 카드마다 다음이 있습니다.

- **경로 모양, 거리, 예상 시간, 추천 점수, 출발 시각**
- **추천 문장:** 계산 결과로 만든 문장. AI 문장(선택 기능)을 켜면 사실 검증을 통과한 문장으로 바뀝니다.
- **안전 평가:** 안전 점수와 단계(양호, 주의, 위험). **항목별 근거**를 펼치면 기온, 강수, 바람, 자외선, 시간대, 조명, 그늘, 차량 노출, 노면, 시설, 공원의 상태와 출처(예보, OSM 기록, 팀 추정)가 나옵니다. 데이터가 없는 항목은 "확인 불가"로 표시하고 안전하다고 보지 않습니다.
- **더 안전한 대체 코스:** 위험 수준이 낮거나 안전 점수가 10점 이상 높은 코스가 있으면 함께 권합니다.
- **점수 근거 보기:** 반려견 특성, 사용자 선호, 거리·시간, 날씨, 안전, 과거 선호도별 점수와 근거. 반영하지 않은 항목은 "반영하지 않았어요"로 밝힙니다.

목록 아래 **위험 조건으로 제외한 코스**를 펼치면 빠진 코스와 이유를 볼 수 있습니다. 모든 시간이 위험하면 코스 대신 이유와 실내 대안을 안내합니다.

안전 점수는 환경 위험을 비교하는 참고값이며 의학적, 절대적 안전을 보장하지 않습니다.

## 6. 산책 코스 탐색

<img src="images/screens/map.webp" width="240" alt="산책 코스 지도. 조건 필터와 지도, 코스 비교 표" align="right" />

**지도**에서 조건(오늘 추천, 30분 이하, 공원 지나요, 그늘 많음)으로 코스를 거르고, 거리·시간·그늘을 표로 비교합니다. 추천순, 짧은순, 한산한순으로 정렬할 수 있습니다.

줄을 누르면 경로, 코스 설명, OSM 도로 기록, 코스 주변 시설(300m 안의 음수대, 공원, 편의점, 반려용품점, 화장실 등)과 데이터 출처가 펼쳐집니다. 줄을 왼쪽으로 밀거나 **이 코스로 산책**을 누르면 바로 길 안내가 시작됩니다.

경로와 시설은 OpenStreetMap 기준이고, 혼잡도·그늘·노면·난이도는 팀 추정값입니다.

## 7. GPS 산책 기록

<img src="images/screens/navigate.webp" width="240" alt="GPS 길 안내. 약 250m 쭉 가세요, 진행률 21%" align="right" />

### 추천 코스로 걷기 (길 안내)

**이 코스로 산책**을 누르면 전체 화면 지도가 열리고 현재 위치를 따라 안내합니다.

| 상황 | 안내 |
|---|---|
| 출발점에서 3km 초과 | 코스 위치를 보여 주고, 카카오맵 길찾기와 시연용 걷기를 제공 |
| 출발점에서 3km 이내 | 실제 도보 경로로 출발점까지 안내 (길찾기 서버 실패 시 직선 표시) |
| 코스 위 | 다음 회전 방향과 거리, 진행률, 남은 거리와 시간. 내 위치를 따라 지도 이동 |
| 코스 이탈 (약 35m 초과) | 벗어난 거리를 알리고 돌아갈 도보 경로를 다시 찾아 점선으로 표시. 돌아오면 이어서 안내 |
| 날씨 악화 | 5분마다 또는 **대체 경로** 버튼으로 재평가. 복귀 경로와 대체 코스 안내 |
| 완주 또는 산책 끝내기 | 실제 걸은 시간과 거리로 기록하고 피드백 화면으로 이동 |
| GPS 사용 불가 | 이유를 안내하고 시연용 걷기나 GPS 없이 기록하기를 제공 |

시연용 걷기는 코스 예상 시간으로 기록하고 활동 통계에서 뺍니다. 피드백 학습에는 반영됩니다.

휴대폰에서 실제 GPS를 쓰려면 HTTPS가 필요합니다. 방법은 [휴대폰에서 실제 GPS 쓰기](SETUP.md#휴대폰에서-실제-gps-쓰기)에 있습니다.

**날씨 재평가의 한계:** 시간별 예보로 판단합니다. 실시간 강수 감지가 아니므로 하늘 상태도 함께 살펴 주세요.

### 내 길을 기록하기

<img src="images/screens/my-walks.webp" width="240" alt="나의 산책길. 산책 기록 시작, GPX 가져오기, 산책길 만들기와 저장한 산책길 목록" align="right" />

추천 코스와 별개로, 직접 걸은 길을 기록해 모아 둘 수 있습니다. **산책 기록** 메뉴의 **GPS로 산책 기록**이나 **마이 > 나의 산책길**에서 시작합니다.

| 기능 | 동작 |
|---|---|
| 산책 기록 | 시작, 일시정지, 재개, 종료. 지도에 이동 경로와 현재 위치를 그리고 거리, 시간, 평균 속도를 보여 줌 |
| GPS 오차 거르기 | 정확도 50m를 넘는 좌표, 제자리 흔들림, 시속 43km를 넘는 순간 이동은 거리에 넣지 않음. 튄 위치가 같은 곳에 3번 연달아 찍히면 실제로 옮겨 간 것으로 보고 새 구간으로 이음 |
| 기록 유실 방지 | 좌표를 받을 때마다 기기(localStorage)에 임시 저장. 새로고침하거나 앱이 닫혀도 다시 열면 일시정지 상태로 불러옴. 저장이 실패해도 기록을 지우지 않고, 다시 저장해도 한 번만 저장됨 |
| 저장 | 이름, 반려동물, 메모, 공개 범위. 거리와 평균 속도는 서버가 좌표로 다시 계산하고, 일시정지 구간 사이는 거리에 넣지 않음 |
| 나의 산책길 | 경로 썸네일 목록. 최근 기록순, 거리순 정렬과 반려동물별, 공개 범위별 보기. 상세 화면에서 수정, 삭제, GPX 다운로드, 공유 |
| 사진 | 저장할 때나 상세 화면에서 5장까지. 브라우저에서 1600px JPEG로 다시 그려 올리고, 서버도 EXIF(촬영 위치), XMP, 주석, 끝에 붙은 보조 이미지를 지운 뒤 저장. 사진은 주인만 보고 공유 화면에는 나오지 않음 |
| 공유 | 링크 공유는 추측할 수 없는 32자 토큰을 쓰고 기간(7일, 30일)을 정할 수 있음. 링크 해제, 비공개 전환 시 예전 링크는 다시 열리지 않음. 공개로 두면 공개 산책길 목록에 올라감 |
| 추천 후보 | 저장하면 기록한 길, 가져온 GPX, 자동 생성한 길 모두 바로 내 추천 후보 코스가 됨. 공용 코스와 같은 엔진으로 점수를 매기고, 지도와 길 안내, 피드백 학습도 같게 동작. 나에게만 보임. 상세 화면의 **추천 후보에서 빼기**로 빼고 다시 넣을 수 있음 |

**추천 후보로 쓸 때:** 주변 도로, 조명, 노면, 나무, 공원은 시드 코스와 같은 방법으로 OpenStreetMap에서 측정합니다. 공개 Overpass 서버가 느려(실측 15~40초) 저장은 바로 끝내고 측정은 뒤에서 하며, 그동안이나 측정에 실패한 항목, 측정할 수 없는 혼잡도와 경사는 "확인 불가"로 계산하고 안전하다고 보지 않습니다. 직접 기록한 길은 반려견이 걸어 본 익숙한 길로, 가져온 GPX는 낯선 길로 봅니다. 서비스 지역(망원동, 개포동) 5km 안에서 출발하는 0.1~10km 산책길만 후보가 되고, 끊긴 구간 사이가 100m를 넘으면 하나의 코스로 잇지 않습니다. 후보가 되지 못하면 산책길은 그대로 저장하고 이유를 상세 화면에 알려 줍니다. 저장할 때 경로가 지나는 범위(사각형 좌표)를 Overpass 서버에 보냅니다.

**제한:** 사진은 JPG와 PNG만 장당 5MB까지 저장합니다(화면에서 고르면 다른 형식도 JPEG로 바꿔 올림). 휴대폰 화면이 꺼지거나 다른 앱으로 넘어가면 브라우저가 위치 수집을 멈추므로, 화면을 켠 채로 걸어야 합니다. 그 사이 구간은 선을 잇지 않고 거리에서 뺍니다.

## 8. 산책 종료 및 피드백

길 안내에서 완주하거나 **산책 끝내기**를 누르면 실제 걸은 시간과 거리로 기록하고 피드백 화면으로 넘어갑니다. 길 안내 없이 다녀왔다면 **산책** 메뉴의 다녀온 산책 기록(`/walk`)에서 **방금 끝났어요** 또는 **다른 시각에 다녀왔어요**로 기록합니다.

| 피드백 항목 | 쓰이는 곳 |
|---|---|
| 산책 만족도, 반려동물 만족도(1~5점) | 코스 선호 학습, 비슷한 코스로 일반화, 선호 거리 |
| 산책 난이도(쉬웠어요, 딱 좋았어요, 힘들었어요) | 선호 거리 보정 |
| 날씨 만족도 | 날씨가 나빴던 산책은 코스 탓이 아닐 수 있어 학습 비중을 절반으로 |
| 이 코스에 또 갈까요?(또 갈래요, 다른 곳이 좋아요) | 익숙함과 코스 선호 |

피드백을 남기면 그 코스의 선호도가 몇 점에서 몇 점으로 바뀌었는지 보여 주고, 다음 추천에 반영합니다. 한 번의 피드백으로 순위가 뒤집히지 않도록 반영 폭을 제한하므로, 시연 보호자 두부는 같은 코스에 5점을 두 번 남기면 1위로 올라옵니다. 잘못 남긴 산책은 피드백 전이면 지울 수 있고, 피드백을 남긴 기록은 학습에 반영되어 지우지 않습니다.

<img src="images/screens/report.webp" width="240" alt="두부의 주간 리포트. 산책 4번, 누적 7.3km, 115분, 지난주 대비" align="right" />

**마이**에서는 코스 선호도, 학습된 취향(공원, 그늘, 강변 등), 시간대 선호, 최근 피드백 5건을 봅니다. **주간 리포트**는 횟수, 누적 거리와 시간, 평균 산책 시간, 지난주 대비, 일별 기록, 만족도 변화, 선호 코스, 추천 1위와 실제 선택을 비교합니다. 시연용 걷기는 통계에서 빼고 건수만 알려 줍니다.

## 9. 커뮤니티

<img src="images/screens/community.webp" width="240" alt="산책길 커뮤니티. 검색, 전체·내 주변·두부 맞춤 보기, 공유된 산책길 카드" align="right" />

**커뮤니티** 메뉴에서 다른 보호자가 공유한 길을 둘러봅니다. 별도의 게시판이 아니라, 기록한 산책길이 공유되고, 다른 보호자의 길 안내와 산책 기록으로 이어지고, 다시 후기로 돌아오는 구조입니다.

| 기능 | 동작 |
|---|---|
| 공유 | **나의 산책길** 상세의 **커뮤니티에 공유하기**나 커뮤니티의 **산책길 공유**에서 직접 기록하거나 GPX로 가져온 길을 고름. 좌표를 복사하지 않고 원본을 참조함. 산책길마다 한 번, 같은 경로도 한 번만 공유. 자동 생성 경로는 아직 아무도 걷지 않아 공유할 수 없음 |
| 위치 가림 | 원본 출발점과 도착점 반경 100, 200(기본), 300, 500m 안의 지점을 서버가 빼고 공개. 길 중간에 다시 그 근처를 지나도 빼고, 지도, 썸네일, GPX, 길 안내가 모두 가린 경로만 씀. 가리지 않는 선택지는 없음 |
| 탐색 | 최신, 인기, 평점 정렬. 이름과 지역 검색. 지역, 거리, 시간, 난이도, 추천 대상 필터. 더 보기로 12개씩 |
| 내 주변 | 내 주변을 고를 때만 위치를 읽어 5km 안의 길을 가까운 순으로 보여 줌. 위치는 저장하지 않고 요청 본문으로 보냄 |
| 맞춤 추천 | 반려동물의 권장 거리, 보호자가 표시한 추천 대상과 특징, 피드백으로 학습한 취향, 지형, 평점으로 점수를 매기고 근거를 함께 보여 줌 |
| 좋아요와 저장 | 누르는 즉시 화면이 바뀌고 실패하면 되돌림. 보호자마다 한 번만 세고, 저장한 길은 **내 산책길 관리**에서 봄 |
| 후기 | 별점 1~5점, 글, 사진 3장. 산책길마다 한 번만 쓰고 고치거나 지울 수 있음. 내가 공유한 길에는 쓸 수 없음 |
| 산책 인증 | 후기를 쓰는 것은 막지 않고, 이 길을 GPS로 절반 이상 걸은 기록이 있으면 **산책 인증**, 없으면 **일반 후기**로 표시. 시연용 걷기와 직접 입력은 인증되지 않음 |
| 이 산책길로 산책 시작 | 기존 GPS 길 안내로 걷고, 끝나면 피드백을 거쳐 후기로 이어짐. 추천 후보에는 들어가지 않음 |
| GPX 다운로드 | 가린 경로만 담음. 시각, 고도, 원본 이름, 메모, 작성자, 날짜를 넣지 않음 |
| 내 산책길 관리 | 공유한 길, 저장한 길, 작성한 후기, 좋아요한 길. 공개와 비공개 전환, 수정, 공유 해제 |

- **비공개와 공유 해제:** 비공개로 돌리면 주인만 볼 수 있고 좋아요와 후기는 남아 다시 공개하면 돌아옵니다. 공유를 해제하면 좋아요, 저장, 후기를 함께 지우고 원본 산책길은 남깁니다. 원본 산책길을 지우면 공유한 글도 함께 지워집니다.
- **로그인:** 목록, 상세, GPX는 로그인 없이 볼 수 있습니다. 공유, 좋아요, 저장, 후기, 관리는 로그인해야 하며, 시연 보호자로는 쓸 수 없습니다. `AUTH_REQUIRED=true`면 화면 전체에 로그인이 필요합니다.
- **한계:** 가림은 전체 경로의 처음과 끝을 기준으로 하므로, 산책 중간에 들른 집은 가리지 못합니다. 경로가 끊긴 곳에서 숨긴 지점이 대략 어디쯤인지는 짐작할 수 있습니다. 같은 산책길을 링크 공유나 공개 목록으로 함께 열어 두면 그쪽 주소로는 가리지 않은 경로가 열리므로 공유 화면에서 경고합니다. 산책 인증은 브라우저가 보낸 GPS 기록을 믿는 것이라 API를 직접 호출하는 위조까지 막지는 못합니다. 조회수는 세션마다 한 번 올리지만 서버에서 중복을 막지는 않습니다. 커뮤니티는 시드 데이터 없이 빈 상태로 시작합니다.

## 10. GPX 코스

GPX는 다른 앱이나 기기에서 기록한 경로를 주고받는 표준 형식입니다.

| 기능 | 동작 |
|---|---|
| GPX 가져오기 | 파일 선택이나 끌어다 놓기. 업로드 진행률, 검증 결과, 경로 미리보기를 보여 준 뒤 저장. GPX 1.0과 1.1의 트랙(`trk`)과 경로(`rte`)를 읽고, 여러 트랙과 구간, 시각 없는 파일, 같은 경로의 중복 가져오기를 알려 줌 |
| GPX 내보내기 | GPX 1.1, UTF-8. 구간, 시각(UTC), 고도를 그대로 담음. 파일 이름은 `pawpath_산책길-이름_20261031.gpx` |
| 산책길 만들기 | 출발 위치(현재 위치 또는 지도에서 선택)와 산책 시간으로 도보 길찾기를 이용해 순환 경로 후보를 최대 5개 만들어 비교하고 내 산책길로 저장. 기준(시간 오차, 되돌아오는 구간)을 못 넘으면 만들지 못했다고 알림. 반려동물을 고르면 후보를 그 아이의 성향·날씨·일정과 주변 환경(도로, 조명, 나무, 공원, 시설)으로 평가해 맞는 순서로 보여 줌(경사·반려견 출입은 평가하지 않음) |

**제한:** GPX 파일은 10MB, 10만 지점까지 가져옵니다. 보안을 위해 DOCTYPE이나 엔티티 선언이 있는 파일은 읽지 않습니다(XXE 방지).

**공용 GPX 후보 코스:** 공개 GPX로 만든 서울 20개 구의 코스 20개가 들어 있습니다. 출발점이 서비스 지역 5km 안이면 그 지역 추천 후보가 됩니다(망원동 4개, 개포동 3개). 지도에서 GPX 코스를 고르면 출발점, 반환점, 편도 거리, 출처가 보입니다. 적재 방법과 결과는 [GPX 후보 코스](GPX_COURSES.md)에 있습니다.

## 11. 가족 및 계정 관리

가족이 함께 쓰면 **프로필 추가**로 프로필을 더 만듭니다. 로그인할 때 프로필이 여럿이면 "누구의 산책을 기록할까요?" 화면에서 고르고, 머리글의 프로필 버튼으로 언제든 바꿉니다. 프로필별 기록과 가족 전체 기록, 구성원별 통계는 **마이 > 가족 산책 기록**에서 봅니다. 규칙은 [API 명세의 프로필](API.md#프로필)에 있습니다.

### 계정 탈퇴

**마이 > 계정 관리**에서 지워질 데이터를 확인하고 탈퇴합니다. 본인을 다시 확인하고 "탈퇴"를 입력하면 유예 기간 없이 바로 지웁니다.

- 지우는 것: 계정, 세션, 반려동물, 추천, 산책 기록, 피드백, 학습 상태, 산책길, GPS 지점, 사진, 내 코스, 커뮤니티 글과 후기, 좋아요, 저장. 공유 링크와 공개 목록에서도 바로 사라집니다.
- 지운 행은 DB 파일의 빈 공간에도 남지 않게 0으로 덮어씁니다(SQLite). 이미 만든 백업에는 보존 기간(기본 14일)까지 남고, 백업에서 복구해도 되살아나지 않습니다. PostgreSQL은 VACUUM 전까지 지운 행이 데이터 파일에 남을 수 있습니다([한계](POSTGRES.md#한계)).
- 지운 뒤에는 되돌릴 수 없습니다. 산책길은 먼저 GPX로 내려받을 수 있습니다.

백업과 복구의 기준, 명령, 복구하면 달라지는 것은 [백업 및 복구 정책](BACKUP.md)에 있습니다.

## 12. 개인정보 및 주의사항

**위치 정보 처리:** 길 안내 중의 위치는 저장하지 않으며 서버 로그에도 남기지 않습니다. 코스 위에서는 브라우저 안에서 계산합니다. 출발점 길찾기, 복귀 경로, 이탈 시 재탐색을 할 때만 좌표를 OSRM 도보 경로 서버로 보냅니다. 경로가 저장되는 것은 아래 [나만의 산책길](#내-길을-기록하기)에서 사용자가 기록을 저장할 때뿐이고, 산책길을 저장하면 추천 후보로 쓰려고 경로가 지나는 범위를 OpenStreetMap Overpass 서버에 보내 주변 환경을 측정합니다.

**공유 화면에서 빠지는 정보:** 걸은 시각, GPS 정확도, 반려동물, 보호자 정보는 보내지 않습니다. 메모는 허용했을 때만 보이고, 공유용 GPX에는 시각과 고도를 넣지 않습니다. 경로 자체에는 집 주소 같은 위치가 드러날 수 있어 공유 화면을 만들 때 안내합니다.

- **사진:** 브라우저에서 다시 그려 올리고, 서버도 촬영 위치(EXIF) 등 메타데이터를 지운 뒤 저장합니다. 사진은 주인만 보고 공유 화면에는 나오지 않습니다.
- **커뮤니티 위치 가림:** 출발점과 도착점 주변을 가리지만, 산책 중간에 들른 집은 가리지 못합니다. 공유 전에 경로를 확인해 주세요.
