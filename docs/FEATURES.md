# PawPath 기능 정리

2026-10-31 기준입니다. 기능을 세 가지로 나눴습니다.

- **구현 완료:** 동작하고 자동 테스트로 확인한 기능
- **구현 중:** 코드는 있지만 일부만 되거나, 실제 환경 확인이 남았거나, 알려진 문제가 있는 기능
- **미구현:** 코드가 없는 기능

검증 방법과 결과는 [검증 결과](VALIDATION.md)에, 각 기능의 동작 방식은 [README](../README.md)와 [시스템 아키텍처](ARCHITECTURE.md)에 있습니다.

## 구현 완료

### AI 추천
| 기능 | 내용 |
|---|---|
| 반려동물 프로필 | 크기, 나이, 활동량, 성격, 산책 선호도, 더위 민감도, 낯선 환경 반응을 추천용 특성값으로 변환 |
| 보호자 일정 | 산책 가능 시간대, 희망 산책 시간, 하루 횟수 |
| 실시간 날씨 | Open-Meteo 시간별 예보. 실패하면 모의 날씨로 전환하고 화면에 안내 |
| 시간대 추천 | 체감온도, 강수, 바람, 자외선, 일몰을 반려동물 기준으로 평가해 산책하기 좋은 시간 선택 |
| 코스 추천 | 안전 평가를 먼저 하고, 5개 묶음(반려견 특성, 사용자 선호, 거리·시간, 날씨·환경, 과거 피드백)으로 점수를 매겨 TOP 3 선정. 위험 코스는 점수와 관계없이 뒤로, 경로가 겹치는 코스는 한 번만, 다녀온 코스만 남으면 새 코스 하나. 가중치와 버전은 설정으로 변경 가능. [자세히](RECOMMENDER.md) |
| 추천 이유 | 실제 계산 결과로만 문장을 만들고, 추정값은 추정이라고 표시 |
| AI 추천 문장 (선택) | 로컬 Ollama(Gemma 4)가 문장을 다듬음. 사실 검증을 통과한 문장만 쓰고 점수는 바꾸지 못함 |
| 피드백 학습 | 만족도와 재방문 의향으로 코스 선호도, 비슷한 코스 특성, 시간대 선호, 선호 거리, 걸음 속도를 학습. 행동별로 신뢰도를 나누고, 추천을 누르지 않은 것만으로는 부정 평가하지 않음. 학습 전후 점수와 순위 변화를 표시 |
| 추천 평가 | 알고리즘 버전, 후보별 점수, 선택과 출발을 저장하고 Precision@3, Recall@3, NDCG@3, Hit Rate@3, 안전, 개인화 지표를 집계. 실사용과 시연 기록을 분리하고 표본이 적으면 표시. 실제 사용자 데이터로는 아직 검증하지 못함 |

### 안전
| 기능 | 내용 |
|---|---|
| 안전 지수 | 기온, 강수, 바람, 자외선, 시간대, 조명, 그늘, 차량 노출, 노면, 주변 시설, 공원 11개 항목. 항목마다 상태와 데이터 출처 표시 |
| 데이터 없는 항목 | "확인 불가"로 표시하고 안전하다고 보지 않음 |
| 위험 코스 제외 | 폭염에 그늘을 확인할 수 없는 긴 코스, 비 오는 시간의 비포장 코스, 강풍의 강변 코스 등을 이유와 함께 제외 |
| 대체 코스 | 위험 수준이 낮거나 안전 점수가 10점 이상 높은 코스를 함께 제안 |
| 시연용 날씨 | 곧 비, 지금 비, 폭염, 한파, 폭우 시나리오. 화면에 시연용이라고 표시 |

### 지도와 길 안내
| 기능 | 내용 |
|---|---|
| 코스 지도 | OpenStreetMap 기반 실제 경로, 추천 순위별 색, 시설 위치 |
| 주변 시설 검색 | 공원, 반려견 놀이터, 동물병원, 음수대, 화장실, 편의점 등. 출처와 수집일 표시 |
| GPS 길 안내 | 출발점까지 실제 도보 경로, 회전 방향과 거리, 진행률, 남은 거리와 시간 |
| 코스 이탈 | 약 35m를 벗어나면 알리고 돌아갈 도보 경로를 다시 찾음 |
| 걷는 중 날씨 재평가 | 비가 오면 줄이거나 돌아가라고 안내하고 출발점 복귀 경로와 대체 코스 제공 |
| GPS를 못 쓸 때 | 이유를 안내하고 시연용 걷기와 GPS 없이 기록하기 제공 |

### 기록과 분석
| 기능 | 내용 |
|---|---|
| 산책 기록과 피드백 | 산책 만족도, 반려동물 만족도, 난이도, 날씨 만족도, 재방문 의향. 지난 시각의 산책도 기록하고, 잘못 남긴 피드백 전 기록은 지움 |

| 주간 리포트 | 횟수, 거리, 시간, 만족도 변화, 지난주 대비, 선호 코스, 추천과 실제 선택 비교 |
| 시연 데이터 분리 | 시연용 산책은 활동 통계에서 빼고 건수만 표시. 학습에는 반영 |
| 여러 반려동물 | 반려동물별 추천, 기록, 학습 |

### 나만의 산책길
| 기능 | 내용 |
|---|---|
| GPS 산책 기록 | 시작, 일시정지, 재개, 종료. 부정확한 좌표, 제자리 흔들림, 순간 이동을 거리에서 제외 |
| 기록 유실 방지 | 좌표마다 기기에 임시 저장해 새로고침해도 복구. 저장 실패 시 다시 저장해도 한 번만 저장 |
| 산책길 관리 | 경로 썸네일 목록, 정렬과 필터, 상세, 수정, 삭제 |
| GPX 가져오기와 내보내기 | GPX 1.0/1.1 읽기, 1.1로 내보내기. XXE 차단, 10MB와 10만 지점 제한. 실제 기기와 앱 파일 51개로 호환성 확인 |
| 사진 첨부 | 산책길마다 5장. 촬영 위치(EXIF) 등 메타데이터를 지우고 저장, 공유 화면에는 표시하지 않음 |
| 공유 | 추측할 수 없는 링크, 기간 설정, 해제, 공개 목록. 공유 화면에서는 걸은 시각, GPS 정확도, 반려동물, 보호자 정보를 뺌 |
| 추천 후보로 쓰기 | 저장하면 기록한 길과 가져온 GPX 모두 자동으로 내 전용 코스가 되어 공용 코스와 함께 추천. 주변 도로, 조명, 노면, 나무, 공원은 OpenStreetMap에서 측정. 원하면 후보에서 빼고 다시 넣을 수 있음 |

### 산책길 커뮤니티
| 기능 | 내용 |
|---|---|
| 산책길 공유 | 기록하거나 GPX로 가져온 길을 공개, 비공개, 공유 해제. 제목, 설명, 대표 이미지, 특징, 추천 대상. 좌표는 복사하지 않고 원본 참조. 자동 생성 경로는 공유하지 않음 |
| 위치 가림 | 출발점과 도착점 반경 100~500m를 서버에서 빼고 공개. 지도, 썸네일, GPX, 길 안내 모두 적용 |
| 탐색 | 최신, 인기, 평점순. 이름과 지역 검색, 지역, 거리, 시간, 난이도, 추천 대상 필터, 더 보기 |
| 주변과 맞춤 추천 | 위치를 저장하지 않는 주변 검색. 권장 거리, 추천 대상, 학습된 취향, 지형, 평점을 합친 맞춤 추천과 근거 |
| 좋아요와 저장 | 즉시 반영하고 실패하면 되돌림. DB 고유 제약으로 중복 방지. 사용자별 보관함 |
| 후기와 별점 | 산책길마다 1건, 사진 3장. 평균은 읽을 때 집계. 내 길에는 쓸 수 없음 |
| 산책 인증 | GPS로 절반 이상 걸은 기록이 있으면 산책 인증, 없으면 일반 후기로 구분 |
| 산책으로 잇기 | 이 산책길로 GPS 길 안내, 산책 기록, 피드백, 후기까지 이어짐. 추천 후보에는 넣지 않음 |
| 공개용 GPX | 가린 경로만 담고 시각, 고도, 원본 이름, 메모, 작성자, 날짜 제거 |
| 내 산책길 관리 | 공유한 길, 저장한 길, 작성한 후기, 좋아요한 길. 공개 상태 변경, 수정, 해제 |
| 삭제 정합성 | 공유 해제, 원본 삭제, 계정 탈퇴 때 좋아요, 저장, 후기, 사진을 함께 지우고, 다른 보호자의 산책 기록은 유지 |

### 계정
| 기능 | 내용 |
|---|---|
| 가족 프로필 | 대표 계정 하나에 프로필 최대 5개(대표 포함). 넷플릭스식 선택 화면, 상단 메뉴로 재로그인 없이 전환, 이름과 아바타 수정, 대표 프로필 삭제 불가 |
| 프로필별 기록 | 산책 기록, 피드백, 추천, 일정, 나만의 산책길이 프로필마다 남음. 반려동물과 학습한 취향은 가족 공용. 남의 기록은 보기만 하고 고치기는 만든 프로필이나 대표 프로필만 |
| 가족 산책 기록 | 가족 합계, 구성원별 산책 통계, 반려동물별 산책 수, 최근 가족 산책. 지운 프로필의 기록도 남음 |
| Google 로그인 | 유일한 로그인 방식. 처음 로그인하면 바로 가입. OAuth 2.0 / OpenID Connect(PKCE, state, nonce), HttpOnly 세션 쿠키. 팀이 실제 Google 클라이언트로 확인 |
| 계정별 데이터 분리 | 반려동물, 추천, 기록, 산책길, 사진, 내 코스를 다른 계정이 볼 수 없음 |
| 로그인 필수 설정 | 기본은 로그인 없이 시연 보호자로 사용. `AUTH_REQUIRED=true`로 로그인 필수 |
| 세션 만료 | 로그인 후 30일 또는 7일 미사용 시 종료. 시연 보호자로 넘어가지 않고 보던 화면 위에서 Google 다시 로그인을 안내하며, 로그인하면 보던 주소로 돌아옴. 저장하지 않은 산책 기록은 기기에 남음 |
| 본인 재확인 | 탈퇴 전 Google로 다시 확인. 10분 유효, 확인하면 세션 토큰 교체 |
| 계정 탈퇴 | 지울 데이터 표시, 유예 없이 즉시 삭제. 공유 링크 차단, DB 파일의 빈 공간까지 덮어씀 |

### 지역과 데이터
| 기능 | 내용 |
|---|---|
| 코스 | 망원동 10개, 개포동 6개. 서버 설정 `SERVICE_AREA`로 지역 전환 |
| 코스 데이터 | OSRM 도보 경로, OSM 시설과 도로·조명·노면·나무·공원 실측값 |
| 옛 DB 자동 보강 | 서버를 시작하면 새 테이블과 컬럼을 데이터 손실 없이 추가 |
| 백업과 복구 | SQLite 자동 백업(24시간), 14일 보존, 검증, 복구 명령. 복구해도 탈퇴 계정, 끝난 세션, 해제한 공유가 되살아나지 않음. [정책](BACKUP.md) |

## 구현 중

| 기능 | 남은 것 |
|---|---|
| GPS 길 안내와 산책 기록 | 실제 휴대폰으로 걸어 보지 않음. 브라우저 위치 에뮬레이션으로만 확인 |
| iPhone 지원 | 같은 엔진인 WebKit으로만 확인. 실제 iPhone Safari는 미확인 |
| 휴대폰에서 Google 로그인 | 고정 도메인을 Google 콘솔에 등록해야 함. 개발 서버(localhost)에서만 확인 |
| Google 본인 재확인 | 가짜 Google 서버로만 확인. Google 문서상 비밀번호를 다시 묻게 강제할 수 없어 계정 선택과 계정 일치만 확인 |
| 백업 | 기본 위치가 DB와 같은 디스크. PostgreSQL 자동 백업은 배포 서버 cron(`scripts/backup_postgres.sh`)만 하고, 복구 명령과 복구 뒤 처리는 직접 |
| 가족 프로필 | 프로필에 잠금(PIN)이 없어 같은 계정을 쓰는 가족은 서로의 프로필로 바꿀 수 있음. 지운 프로필 되살리기 화면 없음. 커뮤니티 글은 계정 단위라 프로필별로 나뉘지 않음 |
| 내 산책길 코스 | 혼잡도와 경사는 측정하지 않아 "확인 불가"로 표시. OSM에 관계(relation)로 그린 큰 공원은 공원으로 잡히지 않음 |
| AI 추천 문장 | 로컬 Ollama만 지원. 품질은 몇 가지 날씨 조건만 직접 읽어 확인 |
| PostgreSQL | 지운 행이 VACUUM 전까지 데이터 파일과 WAL에 남음. 배포 서버의 실제 데이터 이전은 하지 않음. 시연 보호자 id 1 충돌은 시퀀스를 맞춰 고침 |
| 산책길 커뮤니티 | 실제 휴대폰으로 걷지 않음. 산책 인증은 브라우저가 보낸 GPS 기록을 믿으므로 API 직접 호출 위조는 막지 못함. 조회수 중복과 글, 후기 작성 횟수 제한 없음. 신고와 관리자 숨김 기능 없음. 산책 중간에 들른 집은 가리지 못함 |
| 요청 크기 제한 | 크기 표시 없이 나눠 보내는(chunked) 큰 요청은 막지 못함 |
| 로그인 시도 제한 | 서버 메모리에 두어 재시작하면 초기화되고, 서버를 여러 대 띄우면 서버마다 따로 셈 |
| 사진 저장 | DB에 바로 저장. 업로드와 가입 횟수 제한 없음 |
| 코스 추정값 | 혼잡도, 그늘, 난이도는 팀 추정값이며 현장에서 확인하지 않음 |

## 미구현

| 기능 | 이유 또는 현재 대안 |
|---|---|
| 화면이 꺼진 상태의 백그라운드 GPS 기록 | 웹 브라우저의 한계라 네이티브 앱이 필요. 끊긴 구간은 거리에서 빼고 안내 |
