# PawPath 기능 정리

2026-10-31, `main` 브랜치 `e0f7863` 기준입니다. 기능을 세 가지로 나눴습니다.

- **구현 완료:** 동작하고 자동 테스트로 확인한 기능
- **구현 중:** 코드는 있지만 일부만 되거나, 실제 환경 확인이 남았거나, 알려진 문제가 있는 기능
- **미구현:** 코드가 없는 기능

검증 방법과 결과는 [검증 결과](VALIDATION.md)에, 각 기능의 동작 방식은 [README](../README.md)와 [시스템 아키텍처](ARCHITECTURE.md)에 있습니다.

## 구현 완료

### AI 추천
| 기능 | 내용 |
|---|---|
| 반려동물 프로필 | 크기, 나이, 활동량, 성격, 산책 선호도, 더위 민감도, 낯선 환경 반응을 추천용 특성값으로 변환 |
| 보호자 일정 | 산책 가능 시간대, 희망 산책 시간, 하루 횟수 |
| 실시간 날씨 | Open-Meteo 시간별 예보. 실패하면 모의 날씨로 전환하고 화면에 안내 |
| 시간대 추천 | 체감온도, 강수, 바람, 자외선, 일몰을 반려동물 기준으로 평가해 산책하기 좋은 시간 선택 |
| 코스 추천 | 6개 항목(반려동물 적합도, 날씨, 안전, 시간, 과거 만족도, 사용자 선호도) 가중합으로 TOP 3 선정. 가중치는 설정으로 변경 가능 |
| 추천 이유 | 실제 계산 결과로만 문장을 만들고, 추정값은 추정이라고 표시 |
| AI 추천 문장 (선택) | 로컬 Ollama(Gemma 4)가 문장을 다듬음. 사실 검증을 통과한 문장만 쓰고 점수는 바꾸지 못함 |
| 피드백 학습 | 만족도와 재방문 의향으로 코스 선호도, 비슷한 코스 특성, 시간대 선호를 학습. 학습 전후 점수와 순위 변화를 표시 |

### 안전
| 기능 | 내용 |
|---|---|
| 안전 지수 | 기온, 강수, 바람, 자외선, 시간대, 조명, 그늘, 차량 노출, 노면, 주변 시설, 공원 11개 항목. 항목마다 상태와 데이터 출처 표시 |
| 데이터 없는 항목 | "확인 불가"로 표시하고 안전하다고 보지 않음 |
| 위험 코스 제외 | 폭염에 그늘을 확인할 수 없는 긴 코스, 비 오는 시간의 비포장 코스, 강풍의 강변 코스 등을 이유와 함께 제외 |
| 대체 코스 | 위험 수준이 낮거나 안전 점수가 10점 이상 높은 코스를 함께 제안 |
| 시연용 날씨 | 곧 비, 지금 비, 폭염, 한파, 폭우 시나리오. 화면에 시연용이라고 표시 |

### 지도와 길 안내
| 기능 | 내용 |
|---|---|
| 코스 지도 | OpenStreetMap 기반 실제 경로, 추천 순위별 색, 시설 위치 |
| 주변 시설 검색 | 공원, 반려견 놀이터, 동물병원, 음수대, 화장실, 편의점 등. 출처와 수집일 표시 |
| GPS 길 안내 | 출발점까지 실제 도보 경로, 회전 방향과 거리, 진행률, 남은 거리와 시간 |
| 코스 이탈 | 약 35m를 벗어나면 알리고 돌아갈 도보 경로를 다시 찾음 |
| 걷는 중 날씨 재평가 | 비가 오면 줄이거나 돌아가라고 안내하고 출발점 복귀 경로와 대체 코스 제공 |
| GPS를 못 쓸 때 | 이유를 안내하고 시연용 걷기와 GPS 없이 기록하기 제공 |

### 기록과 분석
| 기능 | 내용 |
|---|---|
| 산책 기록과 피드백 | 산책 만족도, 반려동물 만족도, 난이도, 날씨 만족도, 재방문 의향 |
| 마이페이지 | 코스 선호도, 학습된 취향, 시간대 선호, 추천 결과 변화 그래프 |
| 주간 리포트 | 횟수, 거리, 시간, 만족도 변화, 지난주 대비, 선호 코스, 추천과 실제 선택 비교 |
| 시연 데이터 분리 | 시연용 산책은 활동 통계에서 빼고 건수만 표시. 학습에는 반영 |
| 여러 반려동물 | 반려동물별 추천, 기록, 학습 |

### 나만의 산책길
| 기능 | 내용 |
|---|---|
| GPS 산책 기록 | 시작, 일시정지, 재개, 종료. 부정확한 좌표, 제자리 흔들림, 순간 이동을 거리에서 제외 |
| 기록 유실 방지 | 좌표마다 기기에 임시 저장해 새로고침해도 복구. 저장 실패 시 다시 저장해도 한 번만 저장 |
| 산책길 관리 | 경로 썸네일 목록, 정렬과 필터, 상세, 수정, 삭제 |
| GPX 가져오기와 내보내기 | GPX 1.0/1.1 읽기, 1.1로 내보내기. XXE 차단, 10MB와 10만 지점 제한. 실제 기기와 앱 파일 51개로 호환성 확인 |
| 사진 첨부 | 산책길마다 5장. 촬영 위치(EXIF) 등 메타데이터를 지우고 저장, 공유 화면에는 표시하지 않음 |
| 공유 | 추측할 수 없는 링크, 기간 설정, 해제, 공개 목록. 공유 화면에서는 걸은 시각, GPS 정확도, 반려동물, 보호자 정보를 뺌 |
| 추천 후보로 쓰기 | 내 산책길을 내 전용 코스로 등록해 공용 코스와 함께 추천. 주변 도로, 조명, 노면, 나무, 공원은 OpenStreetMap에서 측정 |

### 계정
| 기능 | 내용 |
|---|---|
| 아이디 로그인 | 가입, 로그인, 로그아웃. 비밀번호 scrypt 해시, HttpOnly 세션 쿠키, 연속 실패 시 10분 잠금 |
| Google 로그인 | OAuth 2.0 / OpenID Connect(PKCE, state, nonce). 팀이 실제 Google 클라이언트로 확인 |
| 계정별 데이터 분리 | 반려동물, 추천, 기록, 산책길, 사진, 내 코스를 다른 계정이 볼 수 없음 |
| 로그인 필수 설정 | 기본은 로그인 없이 시연 보호자로 사용. `AUTH_REQUIRED=true`로 로그인 필수 |

### 지역과 데이터
| 기능 | 내용 |
|---|---|
| 코스 | 망원동 10개, 개포동 6개. 서버 설정 `SERVICE_AREA`로 지역 전환 |
| 코스 데이터 | OSRM 도보 경로, OSM 시설과 도로·조명·노면·나무·공원 실측값 |
| 옛 DB 자동 보강 | 서버를 시작하면 새 테이블과 컬럼을 데이터 손실 없이 추가 |

## 구현 중

| 기능 | 남은 것 |
|---|---|
| GPS 길 안내와 산책 기록 | 실제 휴대폰으로 걸어 보지 않음. 브라우저 위치 에뮬레이션으로만 확인 |
| iPhone 지원 | 같은 엔진인 WebKit으로만 확인. 실제 iPhone Safari는 미확인 |
| 휴대폰에서 Google 로그인 | 고정 도메인을 Google 콘솔에 등록해야 함. 개발 서버(localhost)에서만 확인 |
| 내 산책길 코스 | 혼잡도와 경사는 측정하지 않아 "확인 불가"로 표시. OSM에 관계(relation)로 그린 큰 공원은 공원으로 잡히지 않음 |
| AI 추천 문장 | 로컬 Ollama만 지원. 품질은 몇 가지 날씨 조건만 직접 읽어 확인 |
| PostgreSQL | 설정만 있고 연결 미검증. 시연 보호자를 id 1로 직접 넣어 첫 가입이 실패할 가능성이 코드상 보임 |
| 요청 크기 제한 | 크기 표시 없이 나눠 보내는(chunked) 큰 요청은 막지 못함 |
| 로그인 시도 제한 | 서버 메모리에 두어 재시작하면 초기화되고, 서버를 여러 대 띄우면 서버마다 따로 셈 |
| 사진 저장 | DB에 바로 저장. 업로드와 가입 횟수 제한 없음 |
| 코스 추정값 | 혼잡도, 그늘, 난이도는 팀 추정값이며 현장에서 확인하지 않음 |

## 미구현

| 기능 | 이유 또는 현재 대안 |
|---|---|
| 화면이 꺼진 상태의 백그라운드 GPS 기록 | 웹 브라우저의 한계라 네이티브 앱이 필요. 끊긴 구간은 거리에서 빼고 안내 |
| 학습 순위 모델(LightGBM) | 학습 데이터가 없어 바꿔 끼울 구조만 분리 |
| 실시간 강수 감지 | 시간별 예보로 판단하고 화면에 밝힘 |
| 카카오맵, 기상청 API | Leaflet + OpenStreetMap과 Open-Meteo 사용. 카카오맵은 길찾기 링크만 연결 |
| 가로등, CCTV 공공데이터 | 미연동이라 조명은 대부분 "확인 불가" |
| 비밀번호 찾기, 이메일 인증, 계정 연결, 관리자 기능 | 미구현 |
| 안전한 복귀 지점 찾기, 지도 위 대체 코스 동시 표시 | 복귀 목적지는 코스 출발점. 대체 코스는 목록에서 골라 전환 |
| 사용자의 지역 선택 | 서버 설정으로만 전환 |
